# 1D Elastic Collision Simulator

Simulador de colisão elástica unidimensional desenvolvido em Python utilizando Pygame.

## Descrição

O programa simula o movimento de dois blocos em um ambiente fechado. O usuário informa a massa e a velocidade inicial de cada objeto, e a simulação exibe o comportamento dos corpos em tempo real.

A colisão entre os objetos é calculada utilizando as equações de conservação do momento linear e da energia cinética para colisões elásticas.

## Funcionalidades

* Entrada de massa e velocidade para dois objetos.
* Validação dos dados informados.
* Movimento dos objetos na horizontal.
* Colisão com as paredes da simulação.
* Colisão elástica entre os objetos.
* Exibição de massa e velocidade na interface.
* Tamanho dos blocos proporcional à massa.
